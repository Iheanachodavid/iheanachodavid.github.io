# Personal-website
If a page is blank or the photo is missing, the file is not in this folder, or the name is different.

## Add a page later

1. New file, e.g. `thing.html` — copy the header/footer from `csv.html`.
2. Link it from the Work section in `index.html` (`href="thing.html"`).
3. Extra JavaScript goes at the **end** of `script.js`. Do not replace the file.
4. Extra CSS goes at the **end** of `style.css`. Do not replace the file.
5. Save. Refresh the browser.

## GitHub Pages

Repo → Settings → Pages → branch `main` → folder `/` (root).  
Site URL: `https://YOUR-USERNAME.github.io` if the repo is `YOUR-USERNAME.github.io`.
