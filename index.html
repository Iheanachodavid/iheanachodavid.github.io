WHAT I CAN DO

Skills I put to work on every project.

Beyond the three service lanes, these are the concrete capabilities I bring — from shipping a responsive site to keeping the work in Git.

Website Development

I plan, structure and build complete websites from the ground up — pages, navigation, content sections and calls to action — so visitors can find what they need and take the next step.

Responsive Web Design

Layouts that stay readable and usable on phones, tablets and desktops. I design mobile-first, keep tap targets comfortable, and avoid cramped or overflowing pages.

Frontend Development

Clean HTML, CSS and JavaScript (and modern React when it helps) for fast, accessible interfaces. I care about structure, performance and how the site actually feels to use.

Git & GitHub

Version control, clear commits, branches and GitHub workflows so projects stay organised, easy to share, and simple to iterate on over time.

Cybersecurity Basics

Practical security thinking: spotting weak spots, tightening accounts and systems, and explaining risks in plain language so you can act on them.

Data Analysis

Cleaning messy datasets, exploring patterns, and turning numbers into dashboards and insights you can actually use to decide what to do next.

HTML, CSS & JavaScript

The foundations I build on every day — semantic markup, thoughtful styling, and just enough interactivity to make a site feel alive without becoming fragile.

Problem-first Delivery

I start with the problem, not the stack. Economics trained me to look at trade-offs; technology is how I turn that thinking into something people can use.
